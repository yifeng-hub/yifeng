        The current stimulation process is as follows:
        刚开始设好参数后mode写0，sw写1，开始刺激。每个60s后sw写0，会让DA14531进入睡眠；12s后再mode写0,switch写1，重新唤醒；停止13.6分钟也是sw写0。13.6分钟结束时sw写1mode写0。设定时间到了后sw写0。

/*The methods for program modification and debugging are as follows:*/
    1.Make sure that you have installed VSCode and PlatformIO.
    2.The /.pio/libdeps/esp32dev/ui folder in this project was generated by Squareline, but you can also use other software.
    3.You can use "Serial.println" and similar functions for output debugging.
    4.If the program crashes, please try to analyze it from the following perspectives:
        4.1 Make sure that you have entered valid stimulation parameters, some invalid parameters may make the DA14531 crash, and so as the esp32.
        4.2 Use RTOS to leverage the dual-core functionality.
        4.3 Be cautious when using blocking code like delay.
        4.4 Reallocate memory by modifying partition.csv. The esp32 used in this project has 4MB RAM.
